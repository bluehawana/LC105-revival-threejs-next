# Reference images (optional)

Drop fan / Creative-Commons reference photos here — e.g. `transfer.webp`,
`engine.webp` — then point a part at it in `app/lib/lc105-data.ts`:

```ts
reference: "/lc105/transfer.webp",
```

It shows up on that part's detail card. Please only add images you have the
right to redistribute (your own photos, or CC-licensed with attribution).
No Toyota-owned imagery.
